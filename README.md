# 🏏 IPL Intelligence Platform

An AI-powered IPL Decision Support System built using **FastAPI**, **HTML/CSS/JavaScript**, and **Python**. The platform provides player analytics, team insights, auction intelligence, and role-based authentication for IPL franchises, analysts, and administrators.

## 🌐 Live Demo

**Application:** https://ipl-intelligence-5z7k.onrender.com

**API Documentation:**  
https://ipl-intelligence-5z7k.onrender.com/docs

## ✨ Features

- 🔐 Role-Based Authentication
  - Admin
  - Team Management

- 📊 Player Analytics
  - Batting Statistics

# Installation

Clone the repository

```bash
git clone https://github.com/abduldon/ipl-intelligence.git
```

Move into the project

```bash
cd ipl-intelligence
```

Create virtual environment

```bash
python -m venv venv
```

Activate virtual environment

### Windows

```bash
venv\Scripts\activate
```

### Linux / macOS

```bash
source venv/bin/activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python run.py
```

Open your browser

```
http://127.0.0.1:8000
```
