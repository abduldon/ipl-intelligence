# IPL Intelligence

An AI-powered IPL analytics platform for cricket insights, player statistics, and match analysis.

## Features

- Player statistics and performance analysis
- Team analytics
- Match insights
- FastAPI backend
- Interactive frontend

## Project Structure

```
backend/
frontend/
data/
run.py
requirements.txt
```

## Installation

```bash
git clone https://github.com/abduldon/ipl-intelligence.git
cd ipl-intelligence
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python run.py
login page :- http://localhost:8000/login
```

The backend will be available at:

```
http://127.0.0.1:8000
```

API documentation:

```
http://127.0.0.1:8000/docs
```
